# MATLAB / Simulink 故障演示

主演示在 MATLAB 和 Simulink 中完成：原 NPC 电路持续运行，控制台显示三相电流、滤波后相电压、有效值趋势和故障时刻。点击“查看电路模型”可显示实际求解的 Simulink 电路，点击“打开实时 Scope”可显示直接接在模型输出上的电流 Scope。

## 启动与操作

双击桌面 **PowerScope Simulink**，或 `tools/start_simulink_demo.cmd`。启动器打开 MATLAB 演示控制台，同时在本机启动数据记录服务。使用控制台即可操作整套本机演示。MATLAB 启动和首次编译需要等待片刻；录制前先打开并运行一次。

1. 选择 C1 工况，点击“启动仿真”。模型完成初始化并计算 2 s 健康预热后，演示时钟从 0 开始。
2. 观察正常三相电流，再选择“Ta2 开关开路”，点击“注入故障”。开关掩码作用于原模型的门极通路，电感、电容和控制器状态连续保留。
3. 点击“恢复正常”，观察电流及有效值趋势恢复。
4. 选择“A 相传感器卡死”并注入，保持“叠加真实电流（虚线）”勾选。实线显示测量值，虚线显示电路真实电流。
5. 恢复正常后点击“停止并保存”。“打开本次记录目录”可查看 CSV、原始窗口和本次会话的模型版本记录。

“自动 21 秒”依次执行：正常 3 s → Ta2 开路 3 s → 正常 3 s → A 相卡死 3 s → 正常 3 s → C 相偏移 3 s → 正常 3 s。手动注入或恢复会接管自动流程。

故障切换发生在同一次 Simulink 运行中。正常期间继续计算当前电流窗口；故障到来后，窗口随真实模型响应变化。

## 录制画面

建议以 MATLAB 控制台的实时波形为主要画面，用 Simulink 电路图说明功率通路和门极故障注入位置。开路与卡死各展示一次，中间保留恢复过程。模型在录制前完成一次编译和启动，录制时从稳定正常状态开始操作。

Scope 上下两个分图分别显示传感器输出和真实电流，三相使用金色、青绿色与紫色。MATLAB 控制台展示同一条模型数据流，并给出仿真时间与实际时间的比值。一个数据窗口为三相各 500 点、20 kHz 采样、25 ms 仿真时间。显示抽点只作用于绘图，记录和板端输入保留完整窗口。

## 电路来源与数据路径

`powerscope_npc_live.slx` 由研究模型 `npc_diag.slx` 的独立副本生成。原功率电路和 sampled-zoh-v4 dq 控制器保留；固定故障触发替换为可重复操作的故障输入，传感器卡死在每次新故障到来时捕获实际电流。负载侧增加理想 V-I 测量，滤波后相电压以浮动星点为参考。

`matlab/powerscope_bridge.c` 是 Simulink C MEX S-Function，负责故障控制保持、采样、时间节奏和本机窗口传输。电路状态由 Simulink / Simscape Electrical 求解。模块在 `mdlUpdate` 中读取实际模型信号，每 25 ms 发布一个完整窗口。

本机接收器 `pc_monitor/simulink.py` 校验会话标识、长度、序号、时间和有限数值，记录原始样本，并提供既有 DR1 接口所需的归一化窗口。控制台显示的故障输入状态与板端返回的诊断类别分别取自各自来源。

## DR1 接口

DR1、网线和 USB-RS485 接好后，启动命令可带 `-ConnectBoard`，在控制台选择适配器串口并点击“接入 DR1”。数据接口复用既有的逐窗流程：发送当前最新电流窗口，等待板端回执和对应 RS485 结果，再取下一窗。NPU 输入仍为三相共同最大绝对值归一化的小端 float32，合计 6000 字节。

发送请求包含运行标识、序号、波形和 SHA256。新版显示服务声明支持后，可额外接收幅值比例、20 kHz 采样率和仿真时刻，用于 HDMI 屏幕还原电流坐标；这些元数据不进入推理。分类由板端 sfaug-r1 纯 NPU 给出，控制台从真实 RS485 对应帧显示类别、推理耗时和发送至回传耗时。

电脑输入、板端屏幕展示采用既有 HDMI＋USB 触摸屏及原生 Qt 方案，具体接线、启动入口与版本衔接见 [双端演示](HDMI_TOUCH_DEMO.md)。本机可双击 `tools/start_board_display_preview.cmd`，同时预览触摸屏布局中的实际 Simulink 电流波形。

## 构建与记录

- MATLAB：本机 R2023b，Simulink、Simscape Electrical 与现有 MinGW C 编译器。
- 构建入口：`tools/build_simulink_demo.ps1`。编译和模型副本存于 `E:/fpga_workflow_runs/powerscope-simulink-runtime`，研究目录保持原位。
- 原模型、控制器、参数、动态传感器代码、通信模块、生成模型与 MEX 文件均记录 SHA256；开始会话时检查对应关系。
- 本机记录：`artifacts/simulink-live-20261103/sessions/`。每次运行使用独立会话文件，包含 CSV、完整二进制窗口、来源清单与结束记录。
- 短验证入口：`matlab/powerscope_smoke.m`。直接运行生成的 Simulink 模型，将导出窗口与该模型的 `To Workspace` 记录比较，同时检查 KCL、窗口数量及传输完整性。

本机短验证记录见 `reports/simulink-local-20261103.json`：21 s 自动流程收到 840 个完整窗口，数据流用时 21.985 s；最后一个窗口三相各 500 点与 Simulink 原始记录转换为 float32 后逐点相同。全程三相真实电流 KCL 残差最大约 4.77×10⁻⁷ A，卡死段测量值恒定，偏移稳定段误差小于 3.11×10⁻⁷ A。此时间来自模型与记录服务同时运行的短验证；开启控制台和 Scope 时，界面单独显示实际速度。

`tools/verify_simulink_capture.py <会话标识>` 可复核已有的完整自动演示记录，无需重新运行模型。记录保留故障切换边界的实际采样值，包含多采样率模型在边界处的瞬态。

原生界面检查见 `reports/simulink-ui-20261103.json`：手动启动、开路注入、恢复、卡死注入、Scope 打开和停止保存均已实际操作。运行中打开 Scope 的 21 s 自动流程用时 28.084 s；最终浅色 Scope 全程打开时用时 35.247 s，两次均收到全部 840 窗。波形持续刷新，仿真进度以界面中的仿真时间为准。现场录制可根据镜头选择控制台或 Scope 为主画面。

实际界面截图保存在 `artifacts/simulink-live-20261103/output/matlab-console.png` 和 `simulink-scope.png`。
