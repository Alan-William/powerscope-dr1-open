# 验证范围与指标

## 固定数据集

正式模型为 `sfaug-r1`，输入为三相、每相 500 点的电流窗口。板端采用 Alnpu 后端；正式配置 `sensor_rules=false`。

| 输入链路 | 数据范围 | 正确 / 总数 | 准确率 |
| --- | --- | ---: | ---: |
| FPGA Q15 样本回传 → NPU | 固定验证集 | 1090 / 1100 | 99.09% |
| FPGA Q15 样本回传 → NPU | 独立事件 E2 | 4326 / 4400 | 98.32% |
| F32 直接输入 → NPU | 独立事件 E2 对照 | 4327 / 4400 | 98.34% |

以上为不同输入路径下的固定数据评估，不能与连续演示窗口重复统计为同一个测试集。详细模型结构、类别结果及实验背景见 [技术报告](presentation/technical-report.pdf)。公开的 22 窗样本用于演示接口；模型训练协议和选择记录保存在 `models/sfaug-r1/`。
